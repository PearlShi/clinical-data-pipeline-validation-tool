# 软件计划书：临床数据 pipeline 自动化校验工具

## 一、项目背景与目标
临床研究数据的质量校验与标准化处理是生物统计与数据管理工作的核心环节。当前行业普遍依赖人工或零散脚本对临床试验数据进行格式检查、缺失值校验、异常值识别与格式转换，存在效率低、易出错、可复用性差的问题。

本项目旨在开发一套自动化工具，实现临床试验数据（遵循 CDISC 标准）的质量校验、格式转换与批量处理，帮助数据处理人员减少重复工作，提升数据处理的效率与一致性，同时降低人工操作的失误风险。

## 二、核心功能模块
### 模块1：数据格式校验模块
- 支持对 CSV/Excel 格式的临床数据进行基础质量校验，包含：
  1.  变量完整性校验：检查必填变量缺失、变量名不规范/大小写不一致等问题
  2.  数据类型与格式校验：识别数值型变量的非法字符、日期变量格式错误、分类变量取值超出预期范围
  3.  异常值与逻辑校验：识别超出合理范围的数值、不符合业务逻辑的变量组合（如入组日期晚于试验结束日期）
  4.  SDTM/ADaM 标准合规性校验：检查关键变量（如 USUBJID、DOMAIN 标识、时间变量）的命名与格式是否符合 CDISC 规范
- 输出可读性强的校验报告，支持 Markdown（含问题详情与定位）和 Excel（含问题列表、行号、错误描述）两种格式，方便问题追溯与修正。

### 模块2：自动化格式转换模块
- 实现 CSV/Excel 原始数据到 SDTM 标准格式的一键转换，核心能力包括：
  1.  变量映射辅助：基于预设规则与 AI 辅助识别，自动匹配原始变量与 SDTM 标准变量，减少人工配置成本
  2.  标准变量自动生成：自动生成 USUBJID、DOMAIN、STUDYID 等核心标识变量，支持自定义规则配置
  3.  数据格式标准化：统一日期格式、数值精度、分类变量取值（如“是/否”转换为“Y/N”），确保符合行业规范
  4.  转换日志生成：记录转换过程中的关键步骤与修改内容，便于追溯与审计。

### 模块3：可复用脚本与规则配置库
- 封装临床数据处理常用的可复用脚本模板，包含：
  1.  通用数据清洗脚本：缺失值标记、重复记录去重、格式统一
  2.  标准化统计校验脚本：关键指标范围校验、离群值识别、逻辑一致性检查
- 支持用户自定义校验规则与转换配置，通过配置文件即可调整校验逻辑，无需修改核心代码，适配不同试验项目的个性化需求。
- 支持批量数据处理，可对同一目录下的多个数据文件批量执行校验与转换流程。

### 模块4：用户交互界面
- 优先实现命令行工具，支持通过参数指定数据文件、校验规则、输出路径，一键执行全流程处理
- 额外提供基于 Streamlit 的轻量 Web 界面，支持用户上传数据文件、选择校验/转换功能、配置参数、查看处理进度与结果报告，降低非技术用户的使用门槛。
